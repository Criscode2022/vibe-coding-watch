# VibeOS iPhone app

Xcode 15+, iOS 17, a signing team.

1. Pair the ZTE Live 3 as a Bluetooth headset on the iPhone.
2. Open `VibeOS.xcodeproj`.
3. Select your Development Team.
4. Run on the physical iPhone.
5. Set the bridge URL to the Mac Mini Tailscale address, port 7733.

The app plays spoken counts over the watch Hands-Free audio route. Keep Tailscale connected.
